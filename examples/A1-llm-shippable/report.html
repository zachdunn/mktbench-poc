| Conversion rate | 8.1% | 4.4% | 4.4% |

Top-of-funnel metrics (entries, deliverability, open rate, click rate) are **unchanged**. The issue is purely in the conversion step — people see the email, click at the same rate, but then don't convert.

---

## Root Cause: Expired Discount Code in Email Hero Image

The welcome email's hero image (`hero_welcome.png`) contains the welcome offer in static image text with **no live-text code fallback** (per the HTML comment: *"hero contains the welcome offer; no alt text, no live-text code fallback"*).

### Timeline

- **2025-06-01:** Discount code `SOLSTICE10` (10% off first order) was created.
- **2025-06-02:** Welcome flow last edited — hero image was designed featuring the `SOLSTICE10` offer.
- **2026-01-10:** Discount code `WELCOME15` (15% off, but restricted to **Midnight & Terra only**) was created.
- **2026-05-31:** `SOLSTICE10` **expired**.
- **June 2026 onward:** The hero image still shows/promotes the old offer, but the code no longer works. The only active first-order code (`WELCOME15`) is restricted to two product lines, and it's not referenced in the email.

### Why It Wasn't Caught

- The welcome email template was last edited on **2025-06-02** — no one updated the hero image when the discount code changed.
- The offer is baked into a static PNG image, not dynamic/live text, so it didn't auto-update with the code system.
- No alt text was provided, so accessibility/QA checks didn't surface the offer text either.

| **Total (2 months)** | **~$33,768** | **$18,134** | **−$15,634** |
